# 安装、迁移与故障处理

## 新电脑安装顺序

1. 安装 FlClash，导入自己的订阅配置并选中它。
2. 确认该配置在 FlClash 中可以正常连网。
3. 关闭 FlClash 自身的「虚拟网卡/TUN」；不要退出 FlClash。
4. 安装 Python 3.10+。
5. 解压本包；若 `bin\` 下缺少二进制（直接从仓库克隆时常见），先取回并校验：`scripts\Fetch-Binaries.ps1`。
6. 以系统管理员 PowerShell 执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Install.ps1 -ReplaceExistingOverrides
```

7. 等待首次扫描与验收完成。
8. 日常保持规则模式，FlClash 自身 TUN 关闭。

如果目的不是新电脑，而是把本仓库的改动部署到已经在运行的机器上，只需在仓库根目录执行：

```powershell
python src\strategy_manager.py --install
```

## 安装器会改动的内容

- 备份 `database.sqlite`、`shared_preferences.json`、`config.yaml` 和 `profiles`。
- 清除 FlClash 既有脚本覆写、规则覆写和策略组覆写，再绑定本项目脚本。
- 写入 DNS、系统代理、自动启动和静默启动偏好。
- 建立 `%APPDATA%\com.follow\clash\managed`。
- 建立 Windows 服务 `FlClashMihomoService`。
- 建立排程 `FlClash-Strategy-20min` 与 `FlClash-Elevated-AtLogon`。
- 若存在 FlClash 的 HKCU Run 启动项，备份后移除，避免重复启动。

安装器不会关闭或重启 FlClash，也不会把本包中的任何节点或订阅写入目标电脑；本包根本不包含节点凭据。

## 可选安装参数

```powershell
# 不启用独立 TUN；只适合先做兼容性测试
.\scripts\Install.ps1 -ReplaceExistingOverrides -SkipIndependentTun

# 不建立 FlClash 最高权限登录任务
.\scripts\Install.ps1 -ReplaceExistingOverrides -SkipFlClashAutoStart
```

## 常见拒绝原因

- 找不到 Python 或 `pythonw.exe`：安装标准 Windows x64 Python，并启用 Python Launcher。
- 控制端口 9090 不可用：先启动 FlClash；若手动改过外部控制端口，恢复为 9090。
- 配置只有 `proxy-providers`：先在 FlClash 中使用能展开成内联 `proxies` 的订阅配置。
- FlClash 数据库缺少预期表或字段：版本结构不兼容；不要绕过检查。
- 17890/19090 已被占用：释放端口后重试。
- 服务 TUN 启用失败：管理器会恢复先前 TUN 状态；先查看 `managed\manager.log`。

```

```

日志：

```text
%APPDATA%\com.follow\clash\managed\manager.log
```

```powershell
Get-Service FlClashMihomoService
Get-ScheduledTask FlClash-Strategy-20min
Get-NetAdapter -Name MihomoSvc
```

## 恢复

恢复操作会停止独立服务，网络可能中断。先手动退出 FlClash，再执行：

```powershell
.\scripts\Restore-Previous.ps1 -ConfirmRestore
```

脚本只接受安装记录指向的 `managed\backups` 子目录，并在递归删除独立服务目录前核对绝对路径。

## 跨网络迁移后的预期

新的电脑或网络会从零开始累积 `稳净` 样本，并从自己的订阅自动建立 Google/Gemini 候选池。成熟度和节点名单不随 ZIP 迁移，因为旧电脑的结果只代表旧网络条件；初始阶段 `稳净` 显示暂定，普通 MATCH 使用 `极速`，到达成熟条件后自动切换。Netflix 专用组的候选来自 `NETFLIX_PIN_PATTERNS` 匹配的固定线路，若新订阅里没有对应节点，该组会保持上一次可用名单或留空，需要按实际情况调整模式。

## 观察器安装

只读的 Google 旁路观察器与主策略独立部署，需要管理员 PowerShell：

```powershell
.\scripts\Install-GoogleObserver.ps1 -StartNow
```

它会建立排程 `FlClash-Google-Observer-20min`，输出写入 `managed\google-observer`，不切换真实流量。卸载见 [google-observer.md](google-observer.md)。
