# 安裝、遷移與故障處理

## 新電腦安裝順序

1. 安裝 FlClash，匯入自己的訂閱配置並選中它。
2. 確認該配置在 FlClash 中可以正常連網。
3. 關閉 FlClash 自身的「虛擬網卡/TUN」；不要退出 FlClash。
4. 安裝 Python 3.10+。
5. 解壓本包，以系統管理員 PowerShell 執行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Install.ps1 -ReplaceExistingOverrides
```

6. 等待首次掃描與驗收完成。
7. 日常保持規則模式，FlClash 自身 TUN 關閉。

## 安裝器會改動的內容

- 備份 `database.sqlite`、`shared_preferences.json`、`config.yaml`和 `profiles`。
- 清除 FlClash 既有腳本覆寫、規則覆寫和策略組覆寫，再綁定本項目腳本。
- 寫入 DNS、系統代理、自動啟動和靜默啟動偏好。
- 建立 `%APPDATA%\com.follow\clash\managed`。
- 建立 Windows 服務 `FlClashMihomoService`。
- 建立排程 `FlClash-Strategy-20min`與 `FlClash-Elevated-AtLogon`。
- 若存在 FlClash 的 HKCU Run 啟動項，備份後移除，避免重複啟動。

安裝器不會關閉或重啟 FlClash，也不會把本包中的任何節點或訂閱寫入目標電腦；本包根本不包含節點憑據。

## 可選安裝參數

```powershell
# 不啟用獨立 TUN；只適合先做相容性測試
.\scripts\Install.ps1 -ReplaceExistingOverrides -SkipIndependentTun

# 不建立 FlClash 最高權限登入任務
.\scripts\Install.ps1 -ReplaceExistingOverrides -SkipFlClashAutoStart
```

## 常見拒絕原因

- 找不到 Python 或 `pythonw.exe`：安裝標準 Windows x64 Python，並啟用 Python Launcher。
- 控制端口 9090 不可用：先啟動 FlClash；若手動改過外部控制端口，恢復為 9090。
- 配置只有 `proxy-providers`：先在 FlClash 中使用能展開成內聯 `proxies`的訂閱配置。
- FlClash 資料庫缺少預期表或欄位：版本結構不相容；不要繞過檢查。
- 17890/19090 已被占用：釋放端口後重試。
- 服務 TUN 啟用失敗：管理器會恢復先前 TUN 狀態；先查看 `managed\manager.log`。

## 驗收與日誌

```powershell
.\scripts\Verify.ps1
```

執行狀態：

```text
%APPDATA%\com.follow\clash\managed\latest_status.json
```

日誌：

```text
%APPDATA%\com.follow\clash\managed\manager.log
```

Windows 層狀態：

```powershell
Get-Service FlClashMihomoService
Get-ScheduledTask FlClash-Strategy-20min
Get-NetAdapter -Name MihomoSvc
```

## 回復

回復操作會停止獨立服務，網路可能中斷。先手動退出 FlClash，再執行：

```powershell
.\scripts\Restore-Previous.ps1 -ConfirmRestore
```

腳本只接受安裝記錄指向的 `managed\backups`子目錄，並在遞迴刪除獨立服務目錄前核對絕對路徑。

## 跨網路遷移後的預期

新的電腦或網路會從零開始累積 `稳净`樣本，並從自己的訂閱自動建立 Google/Gemini 候選池。成熟度和節點名單不隨 ZIP 遷移，因為舊電腦的結果只代表舊網路條件；初始階段 `稳净`顯示暫定，普通 MATCH 使用 `极速`，到達成熟條件後自動切換。
